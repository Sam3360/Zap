# Zap

![Zap Banner](ZapBanner.png)

Try it here: [https://Sam3360.github.io/Zap](https://Sam3360.github.io/Zap)

Zap is a messaging app that I started building to learn web development. The goal was to create a simple chat platform that people can actually use instead of just making another demo project.

It currently includes:

* User accounts
* Real-time messaging
* User profiles
* Responsive design
* Progressive Web App (PWA) support

I'm still working on improving it and adding new features over time.

## Why I made this

I wanted to challenge myself by building a complete web application from scratch and learn how different parts of a real project work together.

## Tech Used

* HTML
* CSS
* JavaScript
* Firebase

## Current Status

The project is actively being developed and updated regularly.
